# Política de seguridad

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad, **no la publiques como issue**
(es público). Reporta de forma privada por uno de estos canales:

- **GitHub Security Advisories**: usa el formulario de [Reportar una vulnerabilidad](https://github.com/rongorus1/launcher-minecraft-v2/security/advisories/new).
- **Discord**: contacta con los responsables del proyecto en [Discord](https://discord.gg/kZWQrwb64p).

Incluye toda la información posible: versión afectada, pasos para reproducir,
impacto y (si puedes) una sugerencia de mitigación.

## Versiones soportadas

| Versión  | Soportada |
| -------- | --------- |
| 1.0.x    | Sí        |
| < 1.0    | No        |

## Proceso

1. Confirmamos la vulnerabilidad y evaluamos su alcance.
2. Preparamos un fix y lo publicamos en una nueva versión.
3. Después de publicar el fix, reconocemos la aportación del reportador (si lo desea).
