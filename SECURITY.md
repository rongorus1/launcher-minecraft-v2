# Política de seguridad

## Versiones soportadas

Mantenemos soporte de seguridad para la última versión publicada y la anterior.

| Versión  | Soportada |
| -------- | --------- |
| 1.0.x    | Sí        |
| < 1.0    | No        |

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad, **no la publiques como issue** (es público).
Repórtala de forma privada por uno de estos canales:

- **GitHub Security Advisories** (recomendado): https://github.com/rongorus1/launcher-minecraft-v2/security/advisories/new
- **Discord**: contacta con los responsables del proyecto en https://discord.gg/kZWQrwb64p

Incluye toda la información posible:

- Versión del launcher afectada.
- Pasos para reproducir el problema.
- Impacto potencial (qué podría hacer un atacante).
- Sugerencia de mitigación (si la tienes).

## Proceso de respuesta

1. Confirmamos la vulnerabilidad y evaluamos su alcance.
2. Preparamos un fix y lo probamos.
3. Publicamos una nueva versión con la corrección.
4. Reconocernos la aportación del reportador si así lo desea.

## Divulgación

No divulgues la vulnerabilidad públicamente hasta que publiquemos la versión
corregida, para proteger a los usuarios que aún no se han actualizado.
