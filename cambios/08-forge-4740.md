# 08 · Forge 47.4.0

## Problema
Un mod del modpack requiere Forge **47.4.0**; el launcher instalaba 47.3.0.

## Cambios
- `src/config/__init__.py`: `FORGE_VERSION` actualizado de `47.3.0` a `47.4.0`.
- `empaquetar_juego.py`: el marcador del zip preinstalado ya no está fijo; ahora `_leer_version()` lee `MINECRAFT_VERSION`/`FORGE_VERSION` de `src/config/__init__.py` con regex y usa el perfil `f"{mc}-forge-{forge}"`, de modo que el zip siempre refleja la versión configurada.

## Instalación
- Instalado Forge 47.4.0 en el `.minecraft` de empaquetado: primero vanilla `1.20.1` y después `install_forge_version("1.20.1-47.4.0")`.

## Verificación
- `build.bat` regeneró `juego_preinstalado.zip` (4146 archivos, 847.4 MB) con el perfil `1.20.1-forge-47.4.0`.
- Actualizado `launcher_update_1.0.0.zip` (35.0 MB) y re-subido a la Release v1.0.0.
- Refrescado `RongonLang Launcher.zip` (882.4 MB).
